# 🔧 Автосервис: учёт и менеджмент
Консольное приложение на чистом C# с применением ООП и алгоритмов обработки данных.

- учёт заказ-нарядов;
- калькуляция стоимости ремонта и история обслуживания;
- складской учёт товаров и деталей.

**Стек:** C#, .NET, ООП · **Запуск:** открыть `.sln` в Visual Studio → F5
