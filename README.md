## ⭐ Главный проект: автосервис (`PR7`)

Консольное приложение на чистом C# с применением ООП и алгоритмов обработки данных.

- учёт заказ-нарядов;
- калькуляция стоимости ремонта;
- хранение истории обслуживания;
- складской учёт товаров и деталей.

## 🚀 Запуск

1. Установи [Visual Studio](https://visualstudio.microsoft.com/) с нагрузкой **«Разработка классических приложений .NET»** или [.NET SDK](https://dotnet.microsoft.com/download).
2. Склонируй репозиторий (кнопка `Code`, скопировать ссылку -> запустить Visual Studio -> Клонировать репозиторий -> вставка ссылки)
